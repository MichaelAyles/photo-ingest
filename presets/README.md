# presets

Hand-tuned darktable `.xmp` sidecars, one per treatment prompt. Build these in darktable against a representative photo, then export the sidecar here.

Expected filenames (one per prompt in `src/banger/scenes.py`, forthcoming):

- `bw_moody.xmp`
- `golden_landscape.xmp`
- `cinematic_lowlight.xmp`
- `crisp_daylight.xmp`
- `street_punch.xmp`
- `pastel_soft.xmp`
- `documentary_flat.xmp`

Presets are version-coupled to the darktable that made them. Keep the system darktable pinned, or re-export when upgrading.
